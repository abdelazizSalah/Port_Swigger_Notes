# 🛡️ Port_Swigger_Notes

> Personal notes, writeups, and solutions for **PortSwigger Web Security Academy** labs — built while learning offensive security with **Burp Suite**.

---

## 📁 Repository Structure

| Folder | Description |
|--------|-------------|
| `Authentication_Vulnerabilities/` | Labs covering broken auth, brute force, MFA bypass, and session flaws |
| `Command_Injection/` | OS command injection techniques and payloads |
| `Information_Disclosure/` | Exploiting exposed data, stack traces, and hidden content |
| `Network_Penetration_Testing_Methodology/` | General network scanning and enumeration methodology |
| `Path_Traversal/` | Directory traversal attacks and bypasses |
| `SQL_Injection/` | SQL injection techniques from basic to blind and out-of-band |
| `Web_Penetration_Testing_Methodology/` | Web app testing methodology and checklists |
| `burpsuite_intruder_guide.pdf` | Guide on using Burp Suite Intruder for automated attacks |

---

## 🧰 Tools Used

- **Burp Suite** (Community / Pro) — primary interception proxy
- **ffuf / dirb** — directory and parameter fuzzing
- **sqlmap** — automated SQL injection
- **curl / httpie** — manual HTTP requests
